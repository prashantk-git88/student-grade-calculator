# Student Grade Calculator

A Java console application that calculates student grades.

## Features
- Enter student name and marks
- Calculates total marks and percentage
- Displays grade (A, B, C, D, F)

## How to Run
1. Install Java JDK
2. Open in IntelliJ IDEA
3. Run Main.java

## Technologies Used
- Java
- Scanner (user input)
- Conditional statements
